# Проект: оценка эффекта ТВ‑рекламы на продажи чая Ahmad Tea

Учебный проект по анализу эффекта рекламной кампании: детектирование аномалий и событийный анализ (event study) вокруг эфиров ТВ‑рекламы.

## Суть задачи

Оценить, как ТВ‑реклама (по факту эфиров) влияет на динамику продаж бренда Ahmad Tea. Основной фокус — на приросте продаж в окне вокруг эфиров относительно ожидаемого уровня (с поправкой на сезонность и общий тренд).

В проекте реализованы:
- очистка продаж от тренда и сезонности и расчёт остатков (residuals);
- кластеризация дней по режимам продаж (`sales_zscore`, `weekday`);
- событийный анализ эффекта рекламы в окне −5…+5 дней вокруг эфиров;
- проверка устойчивости контрольной группы и статистическая проверка гипотезы.

---

## Основная гипотеза

1. Реклама приводит к росту продаж Ahmad по сравнению с контрольной группой брендов, которые не должны реагировать на эти эфиры.
2. Эффект проявляется не в день эфира, а с лагом 1–3 дня.
3. Эффект неоднороден по кластерам дней: сильнее в «типовых» днях и слабее в изначально высокопродажных режимах.

---

## Данные

### Источники

- Продажи по брендам (в единицах) на ежедневной основе.
- Идентификаторы брендов: Ahmad Tea (ID 178), бренды‑бенчмарки (ID 29 и 5152).
- Даты эфиров — ключевые события, вокруг которых строится анализ.

### Производные метрики

| Метрика | Описание |
| --- | --- |
| `residual_brand_178` | Основная метрика для анализа эффекта рекламы: остатки (факт минус прогноз) по Ahmad Tea, очищенные от тренда и сезонности. |
| `residual_brand_29`, `residual_brand_5152` | Вспомогательные метрики: остатки по контрольным брендам. Используются для проверки устойчивости контрольной группы. |
| `benchmark_diff_29_5152` | Разница продаж контрольных брендов 29 и 5152. Используется как показатель контрольной динамики: стабильность этой разницы подтверждает валидность контрольной группы. |
| `actual_ahmad` | Фактические продажи Ahmad Tea. Используются как вспомогательная метрика для интерпретации масштаба эффекта в натуральных единицах. |

## Методология

### 1. Подготовка и нормализация

- Расчёт z‑score по бренду для продаж (`sales_zscore`) для устранения различий в масштабах между брендами.
- Стандартизация признаков (`StandardScaler`) перед кластеризацией для корректного расчёта расстояний.
- Приведение индексов к типу `datetime` и нормализация дат (удаление времени) для точного сопоставления наблюдений.

### 2. Кластеризация дней

- Использован алгоритм KMeans по признакам `sales_zscore` и `weekday`.
- Для дня недели (`weekday`) учтена циклическая природа: в дополнение к масштабированию возможна альтернативная кодировка (one‑hot или sin/cos‑трансформация) для более корректного учёта соседства дней.
- Интерпретация кластеров выполняется через распределение дней недели внутри каждого кластера (анализ через `value_counts().sort_index()`).

### 3. Событийный анализ (Event Study) вокруг эфиров

Для каждой даты эфира строится окно −5…+5 дней:
- Собираются остатки и контрольные метрики для всех дней окна, где есть данные и в основной, и в контрольной выборке.
- Агрегируются средние и медианные значения по каждому лагу (дню относительно эфира).
- Строятся графики динамики остатков и фактических продаж с выделением дня эфира (lag = 0).

### 4. Проверка гипотезы

- Корреляция Пирсона между `residual_brand_178` и `benchmark_diff_29_5152` — проверка синхронности движений из‑за внешних факторов.
- Парный t‑тест для сравнения периодов «до» (lag −5…−1) и «после» (lag +1…+5) эфира по остаткам Ahmad (по эпизодам).
- Отдельная проверка по кластерам: оценка неоднородности эффекта в разных режимах продаж.

---

## Важные ограничения

- Объём выборки ограничен: небольшое количество эфиров и наблюдений на каждый лаг (порядка 6–7 эпизодов на день). Это существенно ограничивает достоверность статистических выводов.
- Результаты следует рассматривать как предварительные и ориентировочные, а не как окончательное доказательство эффекта.
- Возможны внешние факторы (акции, праздники, сбои поставок), которые могут искажать оценку эффекта рекламы.
